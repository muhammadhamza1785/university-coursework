# Digital Systems and Designs Laboratory

This directory contains my laboratory work completed as part of the Digital Systems and Design course, including lab assignments, System Verilog implementations, simulation results, hardware verification, and supporting documentation. It serves as a record of the practical concepts and digital design techniques explored throughout the course.

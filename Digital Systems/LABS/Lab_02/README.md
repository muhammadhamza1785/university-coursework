# Lab 02: Ripple Carry Adder

This directory contains the complete design, simulation, and hardware project files for **Lab 02: Ripple Carry Adder**. The lab focuses on implementing a foundational 1-Bit Full Adder and cascading three instances to construct a 3-Bit Ripple Carry Adder.

---

##  Directory Structure

```text
Lab_02/
├── Diagrams/           # Architectural block diagrams, QuestaSim waveforms, and WaveDrom timing analyses
├── Questa_Sim/         # QuestaSim project workspace, macro DO-scripts, and binary waveform logs (.wlf)
├── SIM/                # Testbench files (.sv) for functional verification of 1-bit and 3-bit adders
├── SRC/                # SystemVerilog RTL source modules (1-Bit Full Adder and 3-Bit Ripple Carry Adder)
└── Vivado_Project_02/  # Xilinx Vivado projects (project_1 for 1-bit adder & project_2_3bit for 3-bit adder)
